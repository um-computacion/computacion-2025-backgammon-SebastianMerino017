## Prompts de Documentación

# 1. Estructura del Proyecto

“Generá una descripción detallada de la estructura del proyecto Backgammon Computación 2025, explicando el rol de cada módulo (core, cli, pygame_ui, tests) y cómo se relacionan entre sí.”

# 2. Diagrama de Clases

“Creá un diagrama UML del sistema Backgammon que muestre las clases principales (Game, Board, Player, Dice, Checker), las interfaces (CLI, PygameUI) y los módulos de prueba, destacando sus relaciones y dependencias.”

# 3. Lógica del Juego

“Explicá la lógica principal implementada en la clase Game, incluyendo cómo gestiona los turnos, los dados y los movimientos de las fichas, con ejemplos de llamadas a métodos.”

# 4. Arquitectura y Principios

“Describí la arquitectura del sistema y cómo se aplican los principios de la Programación Orientada a Objetos (encapsulamiento, herencia, polimorfismo y abstracción).”

# 5. Interfaz CLI

“Documentá el funcionamiento del módulo CLI, explicando cómo interactúa con la clase Game, los comandos disponibles y cómo se manejan los errores y excepciones.”

# 6. Interfaz Pygame

“Explicá cómo pygame_ui.py representa el tablero gráficamente y se comunica con la clase Game para actualizar la interfaz visual según el estado del juego.”

# 7. Pruebas Unitarias

“Generá una descripción detallada del enfoque de pruebas unitarias del proyecto, mencionando qué clases se testean, qué excepciones se verifican y cómo se mide el coverage.”

# 8. Ejecución del Proyecto

“Redactá una guía breve sobre cómo ejecutar el juego desde la consola (CLI) y desde la interfaz Pygame, incluyendo los comandos necesarios y las dependencias requeridas.”

# 9. Instalación y Dependencias

“Escribí las instrucciones para instalar las dependencias del proyecto (por ejemplo, pygame, pytest) y ejecutar los tests automáticamente.”

# 10. Créditos y Autoría

“Redactá una sección de créditos y autoría con el nombre del autor, materia, institución y año académico.”
